# DataFrame Reporter

Проект содержит класс `DataFrameReporter` для быстрого первичного анализа датафреймов pandas.

Класс позволяет вывести:

- количество строк и столбцов;
- количество и долю дубликатов;
- сводную статистику по данным;
- количество и долю пропущенных значений.

## Установка

Клонируйте репозиторий и перейдите в папку проекта.

Создайте виртуальное окружение:

```bash
python3.12 -m venv venv
```

Активируйте его:

```bash
source venv/bin/activate
```

Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

## Данные

Для запуска проекта поместите файл `payments.csv` в папку:

```text
data/
```

Файл `payments.csv` не хранится в репозитории, поскольку содержимое папки `data/` исключено через `.gitignore`.

## Запуск

Запустите программу из корневой директории проекта:

```bash
python main.py
```
